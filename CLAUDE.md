# CLAUDE.md

Arcades Profile is a database-free Next.js 16 / React 19 site. Follow
`AGENTS.md` for commands, content boundaries, publishing, and newsletter
operations.

Public essays are validated Markdown under `content/posts`. Private drafts are
under `content/drafts`. ActiveCampaign owns contacts and preferences, Postmark
sends email, and Vercel Blob URLs remain in use for media and downloads.
