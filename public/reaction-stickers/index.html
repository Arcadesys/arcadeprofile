    Download skill ZIP

    Skill uploads depend on your account and workspace settings. If Skills is unavailable, use the prompt above.

    Install in ChatGPT
    1. Open Plugins → Skills → Create → Upload from your computer.
    2. Choose the downloaded skill and complete the scan and installation. If the picker asks for an individual skill file, extract the ZIP and select SKILL.md.
    3. Start a new chat, attach your reference, and ask: Use make-reaction-stickers. Standard grouping.

    Skill uploads depend on your account and workspace settings. If Skills is unavailable, use the prompt above. Check ChatGPT skill availability in a new tab.

    Get the plugin package

    The same skill, packaged for a compatible ChatGPT desktop or Codex plugin setup.

    Download plugin ZIP
    Install in desktop Work or Codex
    1. Extract the ZIP and keep the reaction-stickers folder.
    2. In a local Work or Codex chat, attach that folder and ask the built-in plugin-creator to register it in your personal marketplace.
    3. Refresh or restart the app. In the Plugins Directory, choose the local source and install Reaction Stickers.
    4. Start a new chat and attach your character reference.

    A ZIP download alone does not install the plugin. The skill ZIP is the simpler path when your app supports skill uploads.

    Manual Codex skill setup

    Extract the skill ZIP into $CODEX_HOME/skills, or ~/.codex/skills with the default setup. Keep the entire make-reaction-stickers folder and preserve any existing version. Start a new chat, attach a reference, and say Use $make-reaction-stickers. Standard grouping.
